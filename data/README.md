# 데이터 디렉터리

실제 원본·중간·지도 파일은 Git에 커밋하지 않는다. 디렉터리 구조와 재현 방법만 저장소에서 관리한다.

## 역할

| 경로 | 역할 | Git 관리 |
|---|---|---|
| `data/raw/` | 다운로드한 압축 파일 또는 변경하지 않은 원본 | 제외 |
| `data/staged/` | 압축 해제한 원본 CSV | 제외 |
| `data/processed/` | 품질 규칙을 통과한 분석용 Parquet | 제외 |
| `data/reference/maps/` | 로컬 공간 리포트용 역사 지도 | 제외 |

## 역사 지도 기준

현재 히트맵은 현행 지도가 아니라 데이터 수집 기간과 맞춘 지도 후보를 사용한다.

| 맵 | 로컬 파일 | 기준 날짜 | 고정 커밋 | SHA-256 |
|---|---|---|---|---|
| Erangel | `Erangel_2017-11-03.jpg` | 2017-11-03 | `ff1802a5c4139f29535771eb3b37258e6eff1e16` | `47a8c688c4e564f7b69d9cc0283e8bd89cab6794e25e40be26e343984cbda3db` |
| Miramar | `Miramar_2017-12-23.jpg` | 2017-12-23 | `717c33f43e068ff0e856ef7111ab109cfd58c538` | `1a14b6e00b57bce7c6b22e47baecec830cab1ce23e5d56dffb0f42ea9b0b93d0` |

출처는 2017년에 운영된 제3자 GitHub 프로젝트 `moonspell99c/WebMap`의 고정 커밋이다. 공식 PUBG 원본 지도 자산이라고 표현하지 않는다. Erangel 지도는 2017-12-21 버전과 파일 해시가 같고, Miramar 지도는 출시 직후인 2017-12-23 버전이다. 데이터 기간 중 확인된 월드 변경 시점과 비교해 공간 해석용 기준으로 채택했다.

```bash
python scripts/download_map_assets.py
```

다운로더는 파일의 SHA-256을 확인하고 일치하는 파일은 다시 받지 않는다. 지도 파일은 분석 재현을 위해 로컬에만 두며 저장소에서 재배포하지 않는다.

## 좌표 정렬

원본 위치 좌표의 단위는 cm이고 원점은 지도의 왼쪽 위다. 8192x8192 지도에서는 `원본 좌표 / 100`을 이미지 픽셀로 사용한다. 품질 규칙의 유효 상한 816,000cm를 이미지 전체 폭 8192px로 강제 확장하지 않는다.
