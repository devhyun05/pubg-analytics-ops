# Local data storage

이 디렉터리의 실제 데이터 파일은 Git에 커밋하지 않는다.

| 디렉터리 | 역할 | 변경 원칙 |
|---|---|---|
| `raw/` | Kaggle에서 다운로드한 원본 압축 파일 | 수정하지 않음 |
| `staged/` | 압축 해제 및 처리 준비 파일 | 원본에서 재생성 가능 |
| `processed/` | 정제 과정에서 생성한 검증·분석용 Parquet | 파이프라인으로 재생성 |
| `curated/` | 품질 검증을 통과해 최종 채택한 Parquet | 파이프라인으로 재생성 |
| `quarantine/` | 파싱 또는 품질 문제 데이터 | 실패 원인과 함께 관리 |

토큰이나 Kaggle 인증 파일을 이 디렉터리에 저장하지 않는다.
